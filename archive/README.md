# Archive

These are the earlier versions of the prompt. They are kept for the record.

- `flow_designer_prompt_v2.0.md` to `v2.6.md` are the numbered versions. The version history at the end of the current prompt says what each version added.
- `flow_designer_prompt_v2.1_draft.md` is the shorter draft that became version 2.1.
- `flow_designer_prompt2026*.md` are the dated drafts from before the versions had numbers.

Use the current prompt in the top folder of the repository. The `verification/tools/apply_patches_*.py` scripts show how each version was built from the one before it.
